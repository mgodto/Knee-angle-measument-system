モデルの選択
  「自動判定」では、画像のファイル名と保存フォルダー名に含まれる
  Bone/TKA・人工関節あり/なし等の表記からモデルを選びます。
  画像画素から人工関節を診断する機能ではありません。表記がない場合や
  矛盾する場合は、安全側のfallbackとしてMixedを使用します。

  画面のモデル選択欄から「Bone」「TKA」「Mixed」を手動指定できます。
  手動指定は自動判定より優先されます。解析前に、画面上の選択モデルと
  バージョンが対象画像に合っていることを必ず確認してください。

入力画像と両側画像の操作
  新しい画像は常に通常の片側画像フローで開きます。画像を開いただけでは
  分割線やROI操作欄は表示されません。入力画像に両脚が含まれる場合だけ、
  上部の「両側画像を切り出す」を押してROI操作欄を表示してください。

  片側画像:
    患者の解剖学的なL/Rを確認すると、自動解析が始まります。

  両側画像:
    1. 上部の「両側画像を切り出す」を押します。この操作で以前の片側画像
       としての解析結果は消去され、分割線とROI操作欄が表示されます。
    2. 元の検査情報に基づき、患者の解剖学的なL/Rを確認します。
    3. それとは別に、対象脚が画面左側か右側かを確認します。通常のX線表示
       に基づく候補は自動表示されますが、医師が画像上で確認してください。
       必要なら「対象を入れ替え」、画像上の脚のクリック、または分割線で
       修正します。
    4. ROIは分割線を越えて中央側へ画像幅の8%を残します。青いROI表示に
       対象脚全体が入り、反対脚が除外されていることを確認します。
    5. 「ROIを確認して解析」を押します。確認前はAI解析も結果の書き出しも
       できません。
    6. 両側画像の操作を取り消す場合は「片側画像に戻す」を押します。

  L/R、画面上の対象脚、分割線、両側画像モード、AIモデルを変更すると、
  以前の結果は消去されます。ROIを再確認して解析してください。手動修正した
  点が確認済みROIの外へ出た場合も、誤った脚の保存を防ぐため書き出せません。

結果の保存と追跡情報
  両側画像のAI入力だけをROIへ切り出し、表示・手動修正・保存する座標は元画像
  全体の座標へ戻されます。書き出したmeasurement JSONには元画像のファイル名、
  寸法、SHA-256、入力範囲（片側/両側）、モデル情報、手動修正履歴を保存します。
  両側画像ではさらに、確認済みROIのx0/y0/x1/y1、幅・高さ、座標系、選択方法、
  confirmed=trueをanalysis.inference_roiへ保存します。この情報により、学習用へ
  取り込む場合も同じ対象脚だけを安全に切り出せます。

  両側画像の保存名には解剖学的な側を自動で追加します。例: exam.jpgのL側は
  exam_L_measurement.jsonとexam_L_measurement.png、R側は
  exam_R_measurement.jsonとexam_R_measurement.pngです。同じ両側画像でLを
  保存した後、上部をRへ変更し、反対側ROIを確認して保存すれば、L/Rの結果は
  互いに上書きされません。片側画像は従来どおりexam_measurement.jsonと
  exam_measurement.pngです。

起動方法
  macOS: Apple Silicon（M1以降）、macOS 12.1以降。
          ZIPを展開し、KneeXrayMeasurement.appを起動してください。
          初回にブロックされた場合は、Controlキーを押しながらアプリを
          クリックし、「開く」を選んでください。

  Windows: Windows 10/11 x64。
           ZIPを必ず「すべて展開」してから起動してください。
           KneeXrayMeasurement.exeと_internalフォルダーを分離・移動・削除
           しないでください。未署名のため、組織のセキュリティ設定により
           起動が止められる場合は管理者に確認してください。

以前の外部モデル設定が残っている場合
  「AIモデル」メニューから標準の内蔵モデルへ戻してから、上記3種類の
  モデル選択を行ってください。

注意
  - JPG、PNG、BMP、TIFFの片側または両側下肢全長画像を対象とします。
  - DICOMには対応していません。
  - 両脚を含む画像では、必ず「両側画像を切り出す」から対象脚ROIを確認してください。
  - 画像形状から片側/両側を自動判定しません。両側画像モードは医師が必要時だけ起動します。
  - 自動推定した8点、2本の関節線、全角度を必ず医師が確認してください。
  - 評価値は同一データセット内のcase-level 5-fold検証であり、独立施設での
    外部検証は未実施です。診断・治療の唯一の根拠として使用しないでください。
  - パッケージに患者X線画像、教師データ、学習コードは含まれていません。
  - 画像と計測結果は端末内で処理され、ネットワークへ送信されません。
